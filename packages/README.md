# Install helpers

Copy-and-use helpers. They are not published to npm or the WordPress directory; see the install guides at https://aydex.cloud/guides.

- `wordpress/aydex-cloud/`: zip this folder and upload it under Plugins > Add New > Upload. Then Settings > aydex.cloud. Only passes `php -l`; not tested inside a live WordPress.
- `next/Aydex.tsx`: copy into your Next.js app and render it in the root layout. Not compiled against a real Next app here.
